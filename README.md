# Kipo Café · Pedidos por WhatsApp
Sitio estático (HTML/CSS/JS), sin build ni dependencias.

- Menú, precios y extras: `catalog.js` · Fotos: `images/` · WhatsApp y horarios: `script.js`
- Probar local: abre `index.html` o corre `npx serve`
- GitHub: sube todos los archivos a un repositorio (Add file → Upload files).
- Vercel: Add New → Project → importa el repo → Framework Preset: **Other** → Deploy.
- Actualizar: edita `catalog.js` en GitHub y haz commit; Vercel republica solo.
